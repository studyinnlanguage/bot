# Weexionic Android App v2.0.0

**Download:** [Weexionic-App.apk](apk/Weexionic-App.apk) — ya upar file par click karein, phir "Download raw" / "View raw" se save karein.

## Install
1. Purani Weexionic app UNINSTALL karein (agar hai)
2. APK par tap karein → "Install unknown app" allow karein
3. App kholein → email + password se login karein (pehli dafa server address "SERVER SETTINGS" mein daalna hoga, uske baad yaad rehta hai)

## Features
- Native Binance-style login (gold theme)
- Home: live USDT balance, RUNNING/STOPPED status, trades today, START/STOP
- Terminal: poora trading terminal (chart, positions, history, settings)
- Account: subscription, logout
