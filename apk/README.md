# Weexionic Android App v3.1.0

**Download:** [Weexionic-App.apk](apk/Weexionic-App.apk) — file par tap karein → "Download raw" / "View raw" se save karein (~3.9 MB).

## Naye (v3.1.0)
- App size 3.9 MB — bundled premium fonts (Space Grotesk + JetBrains Mono), UI sound pack (tap/start/stop/alert/error) aur hi-res dark-gold artwork (splash, home hero, account banner)
- Balance, prices aur PnL ab professional mono font mein (Binance style)
- Tab tap, bot start/stop par audio feedback

## v3.0.0 core (already included)
- **100% NATIVE app — zero WebView, browser kabhi nahi khulta**
- 5 native tabs: Home / Markets (live prices + sparklines) / Chart (candlestick + EMA overlays) / Trades (positions + history) / Account
- Login-loop fix: session persist hoti hai, app wapas kholne par seedha data
- App aur web bilkul alag: app ka apna UI, server sirf data deta hai

## Install
1. Purani Weexionic app UNINSTALL karein (zaroori)
2. APK tap karein → "Install unknown apps" allow karein
3. Login karein — pehli dafa server address poocha jayega, phir yaad rehta hai
